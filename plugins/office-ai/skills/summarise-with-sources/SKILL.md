# Summarise with sources

1. List the files you will read; read every one in full.
2. Write half a page: findings common to all files, then outliers.
3. End every sentence with the file name in brackets, for example `(report_02_litoral.md)`.
4. State only what the files say. If the files disagree or a file lacks the information, say so; never fill the gap.
5. Add a line "Files read: N" and list any file you could not read.
6. Check: pick two sentences and confirm the claim is in the named file; say which two you checked.
