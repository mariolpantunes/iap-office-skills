# Write a skill

1. Start from the user's best result: ask for the task, an input and the output that was good. Write down the steps that made it good.
2. Make a folder named in lowercase with hyphens, for example `reply-to-client`, holding one file `SKILL.md`.
3. Start `SKILL.md` with a header between two lines of `---`: `name` (the same as the folder) and `description`. The description says what the skill does and when to use it, in third person, under 300 characters.
4. Write the body as numbered steps, one action per step, under 60 lines. Include what to do when data is missing (write MISSING) and a final check.
5. Put no passwords, names of private people or real client data in the skill.
6. Test with a realistic request and with one that should NOT trigger it; fix the description if it triggers wrongly.
7. Package: ZIP the folder itself, so the folder is the root of the archive. Upload under Customize, Skills, Create skill, Upload a skill.
8. A skill you upload is private to you until you share it. Review it when your process changes.
